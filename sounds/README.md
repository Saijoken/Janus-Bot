# Sounds Folder

Place your soundboard audio files here.

## For the `$faaahhh` command:

1. Add your audio file named `faaahhh.mp3` (or `.ogg`, `.wav`, etc.) to this folder
2. Supported formats: MP3, OGG, WAV, FLAC, M4A
3. The bot will automatically play it when someone uses `$faaahhh` in a voice channel

## File Requirements:

- File name: `faaahhh.mp3` (or with appropriate extension)
- Format: Any audio format supported by FFmpeg
- Size: Keep files reasonably sized (< 10MB recommended)

## Note:

You'll need FFmpeg installed on your system for audio playback to work:
- Windows: Download from https://ffmpeg.org/download.html
- Make sure FFmpeg is in your system PATH
